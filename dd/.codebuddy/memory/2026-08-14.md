## 实现 BudgetPurchasePricing.vue 完整功能
- 后端接口（`src/api/budget.js`）：
  - `POST /snapshot/queryBgbtuc` 入参 `{ token, bgbtucent, bgbtucld, bgbtuc001, bgbtuc002 }`，可选字段为空时整体不传；返回 `{ master: [...] }`。
  - `POST /snapshot/saveBgbtuc` 入参 `{ token, list: [...] }`，主键为 4 个单头字段 `bgbtucent+bgbtucld+bgbtuc001+bgbtuc002`；DB 无主键→插入；有→更新；前端没传→删除。
  - `POST /snapshot/deleteBgbtuc` 入参 `{ token, bgbtucent, bgbtucld, bgbtuc001, bgbtuc002 }`，`bgbtuc002` 必填；按所有非空字段匹配删除。
- 字段含义：`bgbtucent`(账套/60)、`bgbtucld`(账别/NBYL)、`bgbtuc001`(物料编号)、`bgbtuc002`(年度)、`bgbtuc003`(供应商/采购员)、`bgbtuc005`(本币金额)。
- 页面照搬 `BudgetEntry.vue` 模式：单头+单身、查询、新增/编辑/保存/取消、删除（按单头条件匹配）、导出 Excel 模板、导入 Excel 后自动进入编辑模式、单头字段联动。
- **重要改动（2026-08-14 下午）**：`bgbtuc001`(物料编号) 从单头移到单身，每行独立填写。单头仅剩 `bgbtucent+bgbtucld+bgbtuc002`；查询模式下单头显示可选「物料编号」筛选框（v-if="isQueryMode"，仅查询用）；编辑模式下自动回填按 账套/账别/年度 查询（autoQueryExist 不再依赖物料）；删除按 账套/账别/年度 匹配整个年度数据；保存时 `bgbtuc001` 从行读取。
- **删除确认框（2026-08-14 下午）**：`handleDelete`（按条件批量删除）与 `removeRows`（删除选中行）均加 `ElMessageBox.confirm` 确认；按钮文案「继续确认 / 否」+ `distinguishCancelAndClose: true`，点「否」或关闭不提交删除命令。

## 实现 BudgetPurchasePricingReport.vue 预算采购价格分析表
- 后端接口（`src/api/budget.js`）：新增 `POST /snapshot/queryBudgetPurchaseAnalysis`，入参 `{ token, ent, site, lang, year, month }`，默认值 `ent='60'`、`site='NBYL'`、`lang='zh_CN'`。
- 页面结构参考 `BudgetReport.vue`：单头查询条件（账套/据点/语言/年度/月份）+ 单身数据表格 + 导出 Excel。
- 数据列按 API 规范分组展示：
  - 基础信息：年、月、品号、品名、规格、分群号、分群名、采购单号、入库单号、供应商、供应商名称
  - 数量单价：对账数量、单位、实际采购含税单价、参考供应商、预算采购含税单价
  - 计算列：采购价差、偏差率、差异额
- 计算列中负数标红（`num-neg` 样式）；单价格式化为 4 位小数，偏差率格式化为百分比。
- 表格支持自定义排序（数据行排序，合计行始终置顶）；底部自动汇总对账数量、单价、价差、差异额（偏差率合计留空避免误导）。
- 导出文件名：`预算采购价格分析表_{year}_{month}.xlsx`。
