## 预算录入页 BudgetEntry.vue 调整

### 接口约定
- `querySubject` POST `/snapshot/querySubject`，默认参数：
  ```json
  { "token": "e6338a4acxw502kmf5dwr316ss8u0ymb",
    "glacl002": "", "glacl004": "",
    "glac003": "2", "glac007": "6" }
  ```
  注意 `glac003/glac007` 没有 `l`，与 `glacl002/glacl004` 不同。

- `saveBgbsuc` 提交的 list 复合主键：
  `bgbsucent`（账套） + `bgbsucld`（据点） + `bgbsuc001`（部门） + `bgbsuc002`（年度） + `bgbsucseq`（序号）
  非主键字段：`bgbsuc003`（月份） `bgbsuc004`（科目编号） `bgbsuc005`（本币金额）

### 当前实现约定
- 部门/年度为空 → 禁止编辑单身（`canEditDetail` 计算属性）
- 部门 + 年度 填齐后自动 `queryBgbsuc` 查后端是否已存在数据，存在则自动回填并提示
- 新增行前校验已有行：科目编码非空 + 金额 ≠ 0
- 删除前检查无脏数据（amount 变 0 / 科目清空判定删除）
- 已删除的可见行保留在 `deletedRows` 中参与 `deleteBgbsuc` 提交

### 删除的调试代码
- `queryJson` 文本框（HTML + 脚本赋值 + CSS）全部清除
- `fetchAllAccounts` 中去掉 `if (acctOptions.length > 0) return` 缓存，便于排查
- `handleDeptVisible` 之前被误删后已补回，部门下拉框正常触发 `fetchAllDepts`
