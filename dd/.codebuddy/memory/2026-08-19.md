## BudgetEntry.vue 调整

### 1. 部门下拉预加载
- 现象：部门 `<el-select>` 打开后显示 "No data"。

- 修复：

- 三个发请求入口处把 token 拼好后的 JSON 写入 `requestJson.value`：
  - `handleConfirmQuery`：完整查询请求。
  - `handleSave`：`{ token, list: payload }`。
  - `handleDelete`：完整删除请求。
- 修复 `handleQuery` 中残留的未声明 `queryJson.value = ''`（改为 `requestJson.value = ''`，同时保留已加载的 `deptOptions`）。
