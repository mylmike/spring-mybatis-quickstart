# 2026-08-18

## 新增功能：订单 BOM 递归展阶
- 新增接口 `POST /queryOrderBom`
  - 从 `xmdd_t` 查询订单品号（`xmdd001`）和数量（`xmdd005`）
  - 根据品号递归展开 BOM，返回下阶子件结构
  - 计算逻辑：BOM用量 = `bmba011 * (1 + NVL(bmbb011, 0)) / bmba012`；实际用量 = 父件实际用量 * BOM用量；订单需求用量 = 实际用量 * 订单数量
- 涉及表：`xmdd_t`（销售订单单身）、`bmaa_t`（BOM 单头）、`bmba_t`（BOM 单身）、`bmbb_t`（BOM 损耗）
- 默认账套 `ent=60`，默认据点 `site=NBYL`；BOM 版本取 `bmaa002` 最小的生效版本
- 新增文件：`BomSqlProvider.java`
- 修改文件：`DsdataMapper.java`、`IndexController.java`
- 返回结构（用于前端树形目录）：
  - `tree`：嵌套树，根节点为订单品号（level=1），每层节点带 `children`、`level`
  - `flat`：扁平明细（不含 children），便于表格/导出
  - 节点字段：订单品号、bmba001、bmba009、bmba003、BOM用量、bmba010、实际用量、订单需求用量

## 修复
- `DsdataMapper.java` 补充 `import org.apache.ibatis.annotations.Param;`，修复 `queryBomChildren` 方法中 `@Param` 报找不到符号的问题
- 当前环境 Maven 编译提示“无效的目标发行版：19”，属于 JDK 版本环境问题，代码本身无错

## 调整
- `/queryOrderBom` 返回的 BOM用量、实际用量、订单需求用量 统一 `.setScale(2, HALF_UP)` 保留 2 位小数（含根节点订单需求用量）
- BOM 子件查询过滤已失效记录：`bmba006`（失效日期）必须为 NULL，否则视为已失效不返回
- `/queryOrderBom` 增加可选传入条件 `xmddseq`（订单序号），过滤订单单身行
- `/queryOrderBom` 返回节点（tree 与 flat）增加字段：`订单号`（xmdddocno）、`订单序号`（xmddseq）
- 修复 `/queryOrderBom` 方法内变量名 `docNo`/`seq` 与循环内部取订单返回值同名导致的编译错误，循环内改为 `orderDocNo`/`orderSeq`
- 已把 `pom.xml` 中 `maven-compiler-plugin` 的 `<source>/<target>` 从 `19` 改为 `17`，与 `<java.version>17</java.version>` 保持一致
- 当前 IDEA 2022.2.2 不支持 JDK 24 作为项目 SDK，导致 `RoundingMode` 等标准类报“无法解释符号”。建议安装 JDK 17 并在 IDEA 中添加为 SDK，或升级 IDEA 到 2023.x+/2024.x+
- 部署环境：用户外部 Tomcat（Tomcat 10+，war 部署）运行 JVM 为 JDK 24；项目按 JDK 17 编译（字节码 61），JDK 24 JVM 向后兼容可运行，但 Spring Boot 3.0.2 官方仅支持 Java 17~19，在 JDK 24 上运行存在潜在兼容风险，必要时可将 Tomcat 的 JAVA_HOME 切回 JDK 17
