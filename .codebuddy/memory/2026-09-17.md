# 2026-09-17

## saveSfahuc 保存后同步回写 sfaa_t（新功能）

`IndexController.saveSfahuc`（`@Transactional("secondTransactionManager")`）在保存 sfahuc_t 成功后（insertCount+updateCount>0），按**工单号**把 sfahuc 字段同步回写 sfaa_t：
- 匹配条件（关键，必须对应，避免误更新）：`sfaaent=sfahucent and sfaasite=sfahucsite and sfaadocno=sfahuc001`
- 字段映射（仅当源值非空 且 与目标列不同/目标列为空 才更新）：
  - sfahuc004(订单号) → sfaa022
  - sfahuc005(订单序号) → sfaa023
  - sfahuc006(预计开工) → sfaa019（TO_DATE(YYYY-MM-DD)）
  - sfahuc007(预计完工) → sfaa020（TO_DATE(YYYY-MM-DD)）

实现要点：
- `SfaaMapper.syncSfaaFromSfahuc`（`@UpdateProvider` → `SfaaSqlProvider.syncSfaaFromSfahuc`）。SQL 用 CASE WHEN 实现"非空且不同才更新"，值全用 `#{}` 绑定防注入；日期用 TO_DATE 显式转换。
- Controller 用 `savedRecords` 收集本次已保存(insert/update)的每条 sfahuc（跳过主键为空的 skip 项），循环调用同步；每条同步用独立 try-catch，失败仅记 `sfaaSyncMsg`，**不影响主保存事务提交**。
- 返回新增 `sfaaUpdateCount`、`sfaaSyncMsg`（仅异常时出现）。

约定（延续）：动态查询/更新条件统一"未传或空串 → 忽略"，值用 `#{}` 绑定；可选条件用 `hasText`(`SfahucDeleteSqlProvider`/`ItemDescSqlProvider`) 或 `isBlank`(`IndexController`) 判定。
